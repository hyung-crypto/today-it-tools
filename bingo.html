📖 빙고 사용방법

빠른 시작 판 만들기 칸 채우기 게임 진행 같이 하기 꾸미기·저장 자주 묻는 질문
⚡ 1분 빠른 시작
  1. 판 만들기 → 를 누릅니다.
  2. 🎲 자동 채우기 를 누르면 칸이 한 번에 채워집니다.
  3. 게임 시작 → 을 누릅니다.
  4. 사회자가 부르는 숫자(단어)가 내 판에 있으면 그 칸을 누릅니다.
  5. 목표한 줄 수를 먼저 완성하면 🎉 축하 화면이 나옵니다.
설치나 회원가입은 필요 없습니다. 휴대폰과 PC 어디서든 이 페이지만 열면 됩니다.
1️⃣ 판 만들기 (설정)
  • 빙고 종류 — 숫자 빙고 또는 단어 빙고를 고릅니다.
  • 칸 개수 — 3×3, 4×4, 5×5 중에서 고릅니다. 어린아이와 함께라면 3×3이 좋습니다.
  • 숫자 범위 — 숫자 빙고에서 사용할 숫자 범위입니다. 예: 1~50으로 하면 판마다 숫자가 달라져 더 재밌습니다.
  • B I N G O 머리글 — 5×5 숫자 빙고에서 판 위에 BINGO 글자를 표시합니다.
  • 주제 추천 — 단어 빙고에서 명절·여행·생일·음식·가족·지역명·나라명 중 하나를 고르면, 자동 채우기 때 그 주제 단어로 채워집니다.
  • 가운데 칸 FREE — 3×3, 5×5에서 가운데 칸을 처음부터 체크된 칸으로 둡니다.
  • 승리 조건 — 몇 줄을 완성하면 이기는지 정합니다. (가로·세로·대각선 모두 인정)
2️⃣ 칸 채우기
  • 순서대로 넣기 (숫자 빙고) — 위 주황색 바에 보이는 번호가 다음에 들어갈 숫자입니다. 원하는 칸을 누를 때마다 1, 2, 3… 순서로 들어갑니다. −/＋ 로 번호를 바꾸거나 지정 으로 직접 고를 수 있습니다.
  • 직접 입력 — 칸을 누르고 입력창에 쓴 뒤 Enter를 누르면 다음 빈 칸으로 넘어갑니다. 단어 빙고는 이 방식을 사용합니다.
  • 🎲 자동 채우기 — 숫자 범위나 선택한 주제로 모든 칸을 무작위로 채웁니다.
  • 🔀 섞기 — 채운 값은 그대로 두고 위치만 섞습니다.
  • 채운 칸을 다시 누르면 지워지고, ↩ 되돌리기 로 직전 상태로 돌아갈 수 있습니다.
같은 값은 두 번 넣을 수 없습니다. 빈 칸이 남아 있으면 게임을 시작할 수 없습니다.
3️⃣ 게임 진행
  • 불린 값이 있는 칸을 누르면 체크되고, 다시 누르면 체크가 풀립니다.
  • 완성된 줄은 초록색 테두리로 표시되고, 위에 ○ 빙고 개수가 나옵니다.
  • 부른 숫자·단어 기록 칸에 입력하면 지금까지 나온 값을 한눈에 볼 수 있습니다. (사회자용)
  • 잘못 눌렀다면 ↩ 되돌리기, 처음부터 다시 하려면 체크 초기화.
4️⃣ 같이 하기 (QR · 링크 · 참가 코드)
  • 각자 다른 판 — 같은 규칙으로 사람마다 다른 판이 만들어집니다. 일반적인 빙고 게임 방식입니다.
  • 모두 같은 판 — 내가 만든 판을 그대로 나눠줍니다. 칸을 모두 채운 뒤 사용하세요.
  • QR 만들기 — 화면에 나온 QR을 다른 사람이 휴대폰 카메라로 찍으면 바로 판이 열립니다. 🔗 링크 복사 로 카톡에 보내도 됩니다.
  • 참가 코드 — 코드를 복사해 보내면, 받은 사람이 이 페이지에서 📥 코드로 참가 에 붙여넣어 판을 만듭니다.
사회자는 숫자를 부르고, 참가자는 각자 휴대폰에서 칸을 누르면 됩니다. 종이 없이도 여러 명이 함께할 수 있습니다.
🎨 꾸미기 · 저장
  • 체크 모양 — 색칠, ✕, ○, 도장 중에서 고릅니다.
  • 색상 · 테마 — 체크 색과 화면 분위기(명절·생일·여행·다크)를 바꿉니다.
  • 글자 크기 — 어르신이나 큰 화면에서는 크게 키워 보세요.
  • 🖼 이미지로 저장 — 판을 그림 파일로 저장합니다. 출력해서 종이 빙고로 써도 됩니다.
  • 💾 판 저장 / 📂 불러오기 — 만든 판을 이 브라우저에 저장했다가 다음에 다시 불러옵니다.
💬 자주 묻는 질문
  • 저장한 판이 안 보여요. — 판은 저장한 그 브라우저에만 보관됩니다. 다른 기기나 시크릿 모드에서는 보이지 않습니다.
  • QR이 안 만들어져요. — 파일을 내 PC에서 직접 연 경우에는 인터넷 주소가 없어 QR을 만들 수 없습니다. 이 페이지 주소로 접속하거나 참가 코드를 사용하세요.
  • 소리가 안 나요. — 휴대폰이 무음 모드인지 확인하세요.
  • 순서대로 넣기 버튼이 없어요. — 숫자 빙고 전용 기능입니다. 단어 빙고는 직접 입력이나 자동 채우기를 사용합니다.
